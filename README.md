# Carbon Market — рынок углеродных единиц (вексельная модель)

MVP веб-приложения для торговли углеродными единицами (УЕ) по модели,
приближённой к механизмам Парижского соглашения (ст. 6), с использованием
векселей как промежуточного финансового инструмента между покупкой права
требования и фактическим зачислением УЕ на баланс в реестре.

## Стек (MVP)
- Python 3.11+, FastAPI, Pydantic v2, Uvicorn
- Хранилище: in-memory (репозитории на dict), легко заменяется на Postgres
- Аутентификация: собственный токен-стор in-memory (заглушка под будущий JWT/OAuth)
- Интеграция с реестром УЕ: `RegistryClient` — заглушка с тем же интерфейсом,
  что будет у реального клиента (freeze/unfreeze/transfer/get_balance)

## Запуск
```
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Откройте **http://127.0.0.1:8000** — там сразу веб-интерфейс (папка `static/`,
обычный HTML/CSS/JS без сборки, обращается к тому же API). Swagger-документация
API — на **http://127.0.0.1:8000/docs**.

При старте `main.py` засеивает несколько демо-пользователей (физлицо, юрлицо)
и демо-остатки в псевдо-реестре, чтобы сразу можно было погонять сценарии.

Демо-доступы (уже подставлены в форму входа):
- Покупатель (физлицо): `buyer@example.com` / `demo1234`
- Продавец (юрлицо, есть готовое объявление на 5000 УЕ): `seller@example.com` / `demo1234`

## Интерфейс (`static/`)
Обычная схема сайта: шапка с логотипом, навигацией и кнопкой «Войти»
справа (после входа — имя пользователя с выпадающим меню и выходом).
Форма входа/регистрации скрыта в модальном окне и не занимает место на
странице, пока не понадобится.

- **Витрина** — доступна БЕЗ авторизации: все предложения продавцов,
  сортировка, фильтр по характеристикам. Здесь же — подбор лучшего
  предложения под точный объём или под бюджет: перед покупкой показываются
  топ‑5 самых дешёвых подходящих предложений (продавец, цена, условия
  сделки), и только после подтверждения оформляется сделка. Покупка (как
  через подбор, так и напрямую по объявлению) требует входа — если
  человек не авторизован, попытка купить открывает окно входа и после
  успешного входа сама завершает то действие, которое он начал.
- **Мои объявления** / **Мои векселя** — приватные разделы: без входа
  показывают приглашение авторизоваться вместо содержимого.

Фронтенд общается с API через `fetch`, токен хранится в `localStorage`
(обычная практика для такого приложения — не ограничение песочницы).
