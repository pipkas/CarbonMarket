# Carbon Market — рынок пронумерованных векселей на углеродные единицы

MVP веб-приложения для торговли углеродными единицами (УЕ). Продавец не
продаёт «сырые» УЕ по цене за штуку — он сначала выпускает («минтит»)
пронумерованный вексель из своего остатка в реестре, и только затем
выставляет ЕГО на продажу за единую фиксированную цену. Купленный вексель
можно перепродать дальше — по номеру векселя можно проверить продавца-
эмитента и всех, через кого он прошёл.

## Стек (MVP)
- Python 3.11+, FastAPI, Pydantic v2, Uvicorn
- Хранилище: in-memory (репозитории на dict), легко заменяется на Postgres
- Аутентификация: собственный токен-стор in-memory (заглушка под будущий JWT/OAuth)
- Интеграция с реестром УЕ: `RegistryClient` — заглушка с тем же интерфейсом,
  что будет у реального клиента (freeze/unfreeze/transfer/get_balance)

## Запуск
```
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Откройте **http://127.0.0.1:8000** — там сразу веб-интерфейс (папка `static/`,
обычный HTML/CSS/JS без сборки, обращается к тому же API). Swagger-документация
API — на **http://127.0.0.1:8000/docs**.

При старте `main.py` засеивает несколько демо-пользователей, демо-остатки
в псевдо-реестре и уже выпущенные/выставленные векселя — включая один
готовый пример перепродажи (вексель, прошедший через двух держателей),
чтобы сразу было что проверить по номеру.

Демо-доступы (уже подставлены в форму входа):
- Покупатель (физлицо): `buyer@example.com` / `demo1234`
- Продавец (юрлицо): `seller@example.com` / `demo1234`

## Интерфейс (`static/`)
Обычная схема сайта: шапка с логотипом, навигацией и кнопкой «Войти»
справа (после входа — имя пользователя с выпадающим меню и выходом).
Форма входа/регистрации скрыта в модальном окне и не занимает место на
странице, пока не понадобится.

- **Витрина** — доступна БЕЗ авторизации: все активные объявления (каждое —
  конкретный вексель по фиксированной цене), сортировка, фильтр по
  характеристикам. Здесь же — подбор лучшей комбинации векселей под точный
  объём или под бюджет: перед покупкой показываются подходящие векселя
  (продавец, номер, цена), и только после подтверждения оформляется
  сделка. Покупка требует входа — если человек не авторизован, попытка
  купить открывает окно входа и после успешного входа сама завершает то
  действие, которое он начал.
- **Проверить вексель** — тоже без авторизации: по номеру векселя
  показывает его паспорт и полную цепочку держателей (кто выпустил, кто
  был промежуточным держателем, кто владеет сейчас).
- **Мои объявления** — приватный раздел продавца: сначала выпустить
  вексель из своего остатка в реестре, затем выставить его на продажу за
  фиксированную цену.
- **Мои векселя** — приватный раздел держателя: обналичить, выставить на
  перепродажу или отменить свою последнюю покупку.

Фронтенд общается с API через `fetch`, токен хранится в `localStorage`
(обычная практика для такого приложения — не ограничение песочницы).
